# Contributing

Thanks for helping improve RankPine for Strapi 5.

## Before opening a change

- Search [existing issues](https://github.com/Blaumaus/rankpine-strapi-plugin/issues).
- Use a supported Strapi 5 release and Node.js 20 or newer.
- Never include API tokens, pairing codes, signing keys, article content, or customer diagnostics in an issue.
- Report vulnerabilities privately using [SECURITY.md](./SECURITY.md), not a public issue.

## Development

```bash
npm install
npm test
npm run validate
npm run build
npm run verify
```

Test changes against a disposable Strapi 5 project before opening a pull request. Pull requests should explain the behavior change, security impact, compatibility range, and focused tests performed.
